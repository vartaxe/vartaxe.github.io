# Windows endpoint automation

Canonical GitHub Pages hub for the
[vartaxe Windows endpoint automation projects](https://vartaxe.github.io/).
It unifies the public profile and the retired ConfigMgr OSD landing page, while the
individual script repositories remain the authoritative sources for code,
documentation, tests, releases, and checksums.

GitHub Pages publishes the dependency-free `index.html`, `style.css`, and local SVG
artwork directly from `main`. The page supports light and dark color schemes,
keyboard navigation, reduced motion, safe-area insets, and a restrictive CSP.

The legacy `/ConfigMgr-OSD/` URL remains a compatibility redirect; it does not
depend on the retired repository. Light and dark button colors use separate
foreground tokens so guide links retain WCAG AA text contrast in either theme.

The site and its original SVG artwork are [MIT licensed](LICENSE). Report content
problems through the [profile repository](https://github.com/vartaxe/vartaxe/issues/new/choose).
For vulnerabilities, follow the [private reporting policy](https://github.com/vartaxe/vartaxe/security/policy).
