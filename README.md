# vartaxe.github.io

Root GitHub Pages site for [Claudio Mendes (`@vartaxe`)](https://github.com/vartaxe).
It redirects visitors to the GitHub profile and provides fallback links to the
[profile site](https://vartaxe.github.io/vartaxe/) and
[ConfigMgr-OSD hub](https://vartaxe.github.io/ConfigMgr-OSD/).

GitHub Pages publishes `index.html` directly from the root of `main`.
